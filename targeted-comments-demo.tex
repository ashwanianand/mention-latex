\title{Targeted Comment Demo}
\author{}
\date{}

\begin{document}
\maketitle

This paragraph contains comments for different co-authors.
Only the active viewer should get the matching margin highlights.

We propose a cleaner proof strategy
\Alice[bob, claire]{Please verify the induction step before we submit.}
for the main theorem.

The terminology in this section
\Claire[alice]{Can you confirm whether ``estimator'' is the right word here?}
still needs one more review pass.

Important requests get a stronger margin box:
\Alice![bob, ashwani]{Please add the missing citation before we freeze the draft.}

Resolved comments stay visible inline, but they do not target anyone:
\Alice[bob, resolved]{This point has already been handled.}

Bob can still reply inline in the usual way:
\Bob[alice, ashwani]{I took care of the comment.}

Adjacent comments for the same active viewer share one margin note:
\Alice[ashwani]{Please check the notation here.}
\Bob[ashwani]{Also verify the citation label.}

The active viewer can come from a local override or from automatic user-id
detection, so only that person's open comments appear in the margin and
contribute to the header count.

\end{document}
